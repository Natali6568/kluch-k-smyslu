# Ключ к смыслу

Интерактивный тренажёр смыслового сжатия текста.

## Версия 1.2.1 — кнопка установки и работа без интернета

После первого успешного входа при подключении к интернету тренажёр можно открывать без сети.  
Локальные файлы приложения сохраняются сервис-воркером, а разрешение на офлайн-доступ — в браузере пользователя.

### Что добавлено

- заметная кнопка «Установить приложение» на главной странице;

- установка как приложения на компьютер, планшет или телефон;
- запуск без интернета после первого успешного входа;
- локальное сохранение прогресса и черновиков;
- индикатор режима «Без интернета»;
- автоматическое получение обновлений при следующем подключении;
- значки приложения 192×192 и 512×512.

### Важно

Первичная регистрация, подтверждение электронной почты и первый вход требуют подключения к интернету.  
Офлайн-доступ действует только на том устройстве и в том браузере, где пользователь уже вошёл.
