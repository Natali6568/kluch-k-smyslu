ОБНОВЛЕНИЕ «КЛЮЧ К СМЫСЛУ»: ПЕРСОНАЛЬНЫЕ ДАННЫЕ

В архиве находятся два файла:
1. index.html — замените файл index.html в корне проекта.
2. js/privacy-consent.js — загрузите этот новый файл в папку js.

Что изменится:
— внизу тренажёра появятся ссылки на Политику и Согласие;
— во вкладке регистрации появится обязательный флажок согласия;
— без установленного флажка регистрация не отправится;
— флажок по умолчанию не установлен;
— в Supabase в user_metadata нового пользователя будут записаны:
  personal_data_consent = true,
  personal_data_consent_at = дата и время,
  privacy_policy_version = 2026-08-04,
  ссылки на Политику и Согласие.
